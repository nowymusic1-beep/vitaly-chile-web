# Vitaly Chile Web

Demo adaptable a móviles de la portada de [Vitaly Chile](https://vitaly-chile.com/).

## Vista local

Descarga el repositorio y abre `index.html` en el navegador. Las imágenes y la tipografía requieren conexión a internet.

Incluye una portada promocional, tres productos y un carrito lateral con cantidades y total en pesos chilenos. El contador y el carrito son de demostración. Las compras se realizan en la tienda original.
